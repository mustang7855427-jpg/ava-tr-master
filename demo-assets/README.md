# Synthetic test assets only

This directory is generated by `utils/generate_demo_assets.py`. The SWF files
are small, valid SWF files containing only simple colored shapes; the XML
archive contains empty parser fixtures. They are suitable for checking asset
downloads, manifest paths, SWF parsing, and backend startup. They are not the
Avataria client, game content, or a playable game.

Keep this directory limited to generated test assets. Do not put original game
assets in it.
